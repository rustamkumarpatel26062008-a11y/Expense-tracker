💰 Expense Tracker

A simple Expense Tracker built with Python to manage income and expenses. It stores financial records in a JSON file.

✨ Features
Add income and expenses
View all expenses
Delete expenses
Filter expenses by category
Calculate total expenses
Calculate total balance
Save data using JSON
🛠️ Technologies Used
Python 3
JSON
datetime
os
📂 Project Structure
Expense-Tracker/
├── main.py
├── exp.json
└── README.md

🚀 How to Run
Install Python 3.
Download or clone the repository.
Open the project folder in your terminal.
Run the following command:
python main.py


No external libraries are required.

🧮 Balance Calculation
Total Balance = Total Income - Total Expenses

🎯 Learning Objectives

This project demonstrates Python functions, loops, lists, dictionaries, exception handling, JSON file handling, and basic calculations.
